# Squad 决策

本领域定义同一工作区内的人机协作编组、成员与维护者、可选 leader 及小队生命周期。
首份决策是[工作区内人机小队](0-workspace-scoped-human-agent-squads.md)。

工作区准入与加入事务属于 [tenancy](../tenancy/20261027-squad-targeted-joining-and-inviter-revocation.md)，
既有 `team` 目标由 [Issue 协作](../issue-collaboration/0-typed-targets-and-explicit-execution-intent.md)
消费。小队编组不拥有另一份人类身份、私人模型凭据或运行时执行生命周期。
