# 共享项目的运行时内容只允许创建者和当前管理员使用

有效成员共享项目及安全运行时概况；内容和普通操作只供运行时创建者与当前租户管理员。
使用权限不取代独占与写活动准入。管理员普通操作也不能抢占另一有效会话。

本决策的创建者迁移、服务授权、概况过滤和重放检查已实现。我的运行时、权限/占用提示及未覆盖
历史/隔离故障矩阵移至[后续 ADR](../execution-admission/20261013-runtime-control-ui-and-fault-acceptance.md)，
核心证据见[权限用例](../../../test-cases/cloud/workspace/runtime-workspace-use-permissions.md)。
第一阶段无成员授权表、授予/撤销接口、创建者转让或实时共同编辑。

## 决策

### D1：持久归属、创建者、操作者和发起者分别记录

`owner_user_id` 保留项目归属/凭据关联；`creator_user_id` 保存真实创建请求者，main 使用项目
创建者。operation actor 保留原发起者，当前控制会话不转移创建者或 owner。管理员只是当前
有效租户角色，不获得跨租户权限。客户端自报身份不能参与授权。

### D2：概况共享，内容及重放重新核验权限

有效成员可读名称、创建者、生命周期和安全状态，服务端以 allowlist 投影过滤概况。代码、任务
文本、命令、分支详情、输出及 operation 内容只供可使用目标者；知道 ID、旧链接或历史 actor
不授权。默认 main 不公开内容，也不能单独删除。

只读内容不需独占，但不能因此越权；修改、执行、生命周期还要求当前操作会话及活动保护。
项目删除保持管理员权限和全项目活动检查。幂等重放返回历史结果前也核验当前权限，成员停用
或管理员降级不能通过成功重放重新获取内容。SSE 在投递时核验当前有效成员，不附受限内容。

### D3：第一阶段没有显式共享授权

当前使用权只有创建者与管理员两个来源，前端按钮不产生第三来源。普通成员共享 Git 分支和
提交通过仓库平台协作，不隐式合并未提交目录。服务返回可使用概况，界面接入属于后续 ADR。

### D4：历史创建者只由唯一创建证据回填

前向迁移 `0018_runtime_creators.sql` 从对应 create operation 的已验证 actor 回填；main 从
项目创建证据回填。缺失或冲突记为 unknown，仅管理员使用，不用 owner、最近操作者或任意
管理员猜测。保留原数据、外键、历史执行及清理引用；新控制表为空不代表旧运行实例空闲。

创建者离开不转移普通成员权限或删除数据，管理员须经安全交接再操作。
[仓库凭据连续性](../project/20260927-repository-credential-continuity.md)由自身后续决策处理。

## 实际同步与不变量

移除旧核查基线和同类产品推测，承诺以已实现授权规则为准。原文要求的浏览器呈现和全部历史
快照矩阵已拆出，不因后端 implemented 宣告完整产品体验已完成。

1. 当前角色、owner、creator、actor 和 session 不能互相替代。
2. 资源 ID、旧链接、历史成功或界面可见不授予使用权。
3. 其它成员只能读取安全概况，详情和重放不能旁路授权。
4. 管理员普通操作同样受独占；角色失效影响下一次校验。
5. 未知创建者仅管理员使用，前向迁移不猜测归属或丢弃恢复引用。
