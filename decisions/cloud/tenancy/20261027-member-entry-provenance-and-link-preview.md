# 成员加入来源与私有链接预检

继承 [一空间一租户](20260923-one-space-per-tenant.md) 的唯一成员权限、7 天单次邀请、30 天多人审批申请、令牌仅存摘要与内网目录加入。来源为 circus #732/#733；当前是待 owner 评审的提案，不代表已批准或上线。与 circus #722/#731 的定向加入决策分别负责展示/来源与小队原子加入，不以本提案推断小队授权。

## D1：只读预检与身份边界

`POST /api/v1/join/links/preview` 接收类型和 token。Gateway 只为此确切方法和路径允许无会话请求，校验同源和限流，移除浏览器提供的内部身份头，以自己的服务身份调用 Cloud。Cloud 仍校验 gateway 服务角色，提供用户身份时必须验证 caller 绑定；企业目录部署关闭此入口。

预检不调用身份创建，不产生用户、成员、申请、幂等或审计写入。匿名仅得到类型和 active/used/expired/revoked/unavailable；未知令牌、失活租户或空间统一 unavailable，不返回租户、人员或使用者。已登录、活动的用户可以获得目标工作区确认信息及自己已加入/待审批的状态。已有有效成员优先进入工作区，即使该邀请已使用或到期；失活工作区不提供进入入口。

预检不是兑换授权。真正写入仍在原事务内重新校验；原 join_link_unavailable 错误码保留，增加安全的 reason 参数。多条件重叠时 used 优先于 revoked，再于 expired；其他不可用统一 unavailable。外部页面永不显示兑换者。

## D2：已有成员不消耗普通邀请

修改此前“已有成员也消费邀请”的实现契约：已是有效成员的用户接受同工作区普通邀请，返回自己的成员状态，不消费 token、不变角色、不记录新的加入。新成员与停用成员必须持有当前有效邀请才可建立/恢复资格。并发与幂等语义不变，单次邀请只使一位真正需要准入的人加入。

## D3：来源是成员变更的持久事实

在建立或恢复成员资格的同一事务追加加入记录，保存租户、用户、方式、发起/授权人、时间及关联邀请或申请。方式包括创建工作区、单次邀请、批准申请、目录添加；开发专用身份不伪装成真实邀请。已有有效成员、重复审批与幂等重放不追加记录。记录不成为第二份权限权威，当前权限仍只来自 tenant_memberships。

管理员可以读当前来源和重新加入历史，普通成员只能读基础名册；服务端承担权限和租户隔离，不能只隐藏按钮。历史迁移不根据 consumed_by 猜测加入，因为旧实现允许已入成员消费 token；无法严格证明的历史来源显示未记录。人员显示名来自当前名册，历史 actor ID 和链接引用永久保留。

## D4：链接管理与兼容

两类链接可带管理备注，不绑定收件人、不改变准入。原文只在生成弹窗内存中存在，关闭、换工作区或离开页面即丢弃；可反复复制同一原文但不增加次数。管理列表提供创建者、时间、状态、使用者或申请统计。生成/撤销/审批失败与空列表区分，用户页面准确区分已使用、到期、撤销及服务故障。

新增前向迁移保存备注与来源记录；保留旧表、摘要、版本和旧客户端兑换错误码。新客户端依赖的新字段由生成契约声明，OpenAPI、生成客户端和中英文文档同步。发布时先迁移，再更新 Cloud 与 Gateway，最后更新前端；旧前端可继续调用原写接口。

## 不变量与验收

- 匿名、伪造用户头、非 gateway 服务不能读成员或人物；预检前后业务表计数和版本不变。
- 并发单人兑换只有一次准入；已有成员不烧掉新邀请，停用者无有效 token 不可重入。
- 每次准入与来源原子提交，重复和重放不增记录，失败不留下半条历史。
- 旧数据来源不伪造，来源详情仅管理员可读且不能跨租户。
- 匿名失效提示、登录恢复、申请审批、复制/关闭、桌面与窄屏中英文均有实际验证。

批准后在 tenancy 核心用例补充证据义务；implemented 落档在产品 PR 合并后由独立运行承接。
