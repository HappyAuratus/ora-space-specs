# 命令的来源、优先级与展示

决策依据：[Agent 插件发现契约](../../../../decisions/desktop/plugin/agent/0-discovery-contract.md)（`approved`）。实现尚未开始，本文件全部义务的证据状态为 `Missing`。

## Session Reported Commands Must Win Over Discovered Ones

### 风险

发现结果可能缺少 MCP 命令或已经过期。它若盖过会话上报，或切换 Agent 后仍展示旧 Agent 的命令，用户会选到不能用的命令。

### 前置状态

- 会话分别：没有上报；实时上报非空；实时上报空列表；只在 setup 得到空列表。
- 发现结果非空。另有一个待执行的 Agent 切换，目标 Agent 有自己的发现结果。

### 触发

打开命令菜单；再选择另一个 Agent 但不发送；再取消选择。

### 必须成立

- 没有待执行的切换且会话已上报（含实时上报的空列表）时，只用会话的列表。
- 会话没有上报，或只在 setup 得到空列表时，用发现结果。
- 存在待执行的切换时，用目标 Agent 的发现结果；取消后恢复。
- 发现结果不写入会话历史，不随会话持久化。

### 禁止结果

- 会话上报空列表后仍展示发现结果。
- 待切换期间展示当前 Agent 的会话列表。

### 验证义务与证据

| 验证义务 | 代表性证据测试 | 状态 |
| --- | --- | --- |
| 会话上报优先，包括实时空列表 | 尚无实现 | `Missing` |
| setup 空列表按没有上报处理 | 尚无实现 | `Missing` |
| 待切换期间使用目标 Agent 的发现结果 | 尚无实现 | `Missing` |
| 发现结果不持久化 | 尚无实现 | `Missing` |

### 决策依据

- D7 第 1、2、4 点与边界。
- 不变量 6、7。

## Unsupported Hints Must Follow The Sending Agents Own Session Report

### 风险

发现不带 MCP，会话已有的列表又可能属于切换前的 Agent。用错来源会把可用的命令标成不支持。

### 前置状态

- 当前 Agent 的会话已上报 `/a`；发现结果只有 `/b`。
- 目标 Agent 的发现结果有 `/c`。

### 触发

分别在会话未上报、已上报、待执行切换时，输入 `/a`、`/b`、`/c` 和不存在的命令。

### 必须成立

- 前端保留命令列表的来源和所属 Agent。
- 只有没有待执行的切换、当前发送目标自己的会话已上报、且列表中没有该命令时，才提示不支持。

### 禁止结果

- 因发现结果中没有该命令而提示不支持。
- 待执行切换时提示不支持。
- 会话未上报时提示不支持。

### 验证义务与证据

| 验证义务 | 代表性证据测试 | 状态 |
| --- | --- | --- |
| 会话未上报时不提示 | 尚无实现 | `Missing` |
| 命令只在发现结果之外时不提示 | 尚无实现 | `Missing` |
| 待切换期间不提示 | 尚无实现 | `Missing` |

### 决策依据

- D7 第 3 点。
- 不变量 11。

## Agent Command Text Must Be Treated As Untrusted

### 风险

命令文本常取自仓库文件，在用户没有发起会话时就自动展示。解释其中的标记、不限长度，或因一条坏数据丢掉整份结果，会带来注入、卡顿或列不出模型。

### 前置状态

- 发现结果和会话上报分别包含：标记、链接和控制字符；空名称、含空白或控制字符的名称、超过 128 bytes 的名称。
- 含 `:`、`-`、`_`、`.` 和非 ASCII 字母的合法名称。
- 501 条命令；超长的描述和输入提示，上限处落在多字节字符中间。

### 触发

展示两种来源的命令，并选择其中一条。

### 必须成立

- 名称、描述和输入提示只按纯文本展示；选择命令只填入输入框；界面标明来自 Agent，与 Ora 管理的 Skill 区分。
- 按 Agent 的顺序保留前 500 条，插件日志记一次 `warn`，只记数量。
- 非法或超过 128 bytes 的名称逐条丢弃，其余条目和模型不受影响；列出的合法字符都接受。
- 描述超过 4096 bytes 在字符边界截断并加省略号；输入提示超过 256 bytes 在字符边界截断。
- 两种来源规则相同，会话交付的内容不因展示限制改变。

### 禁止结果

- 解释标记或链接，或因展示而执行命令。
- 拒绝带插件前缀的名称。
- 截断产生无效的 UTF-8。

### 验证义务与证据

| 验证义务 | 代表性证据测试 | 状态 |
| --- | --- | --- |
| 纯文本展示，选择只填入输入框 | 尚无实现 | `Missing` |
| 条数、名称、描述、输入提示的上限，以及多字节边界 | 尚无实现 | `Missing` |
| 非法条目逐条丢弃，带插件前缀的名称保留 | 尚无实现 | `Missing` |
| 两种来源展示规则相同，会话交付不变 | 尚无实现 | `Missing` |

### 决策依据

- D8 第 1–4 点。
- 不变量 12。

## Info Logs Must Not Contain Full Command Or Skill Lists

### 风险

命令和 Skill 目录列表可能很长，且包含仓库内容。写进默认级别的日志会长期留存。

### 前置状态

- 发现返回多条命令，输入带多个 Skill 目录。

### 触发

以 `info` 级别完成发现，并触发一次条数超限。

### 必须成立

- `info` 及以上级别只记数量等摘要。
- 工作目录、Skill 路径等本机绝对路径可以出现。

### 禁止结果

- `info` 及以上级别出现完整的命令列表或 Skill 目录列表。

### 验证义务与证据

| 验证义务 | 代表性证据测试 | 状态 |
| --- | --- | --- |
| `info` 及以上级别不含完整列表 | 尚无实现 | `Missing` |

### 决策依据

- D8 第 5 点。
