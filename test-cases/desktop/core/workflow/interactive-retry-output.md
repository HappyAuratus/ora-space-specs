# 交互节点自动重试的交付边界

## Only The Final Attempt Can Authorize Successors

### 风险

旧发送的输出与完成请求在自动重试后仍能让后继使用无效输入。

### 前置状态与触发

交互式 Agent 节点的后继依赖其成功。原尝试已输出文本或调用完成工具，随后静默。取消排空中仍可能收到消息。原请求确认取消后，重试只返回 EndTurn。分别从普通完成、自动接受和二次确认的强制完成入口操作；另以新回合交付有效结果。

### 必须成立

- 常规推进被拒绝，后继的实际启动次数为零。卡片和详情均显示节点运行失败，原因与原会话重试入口在刷新后仍可见。
- 当前尝试的有效纯工具交付按冻结契约验收。新旧尝试的工具或消息 ID 相同时仍按各自窗口取值。
- 只有再次确认的 force 可覆盖门禁，审计保存空重试原因，提交输出只来自最终尝试。后续回合正常恢复时保留原失败记录。

### 禁止结果

取消前或取消排空期间的文本被提交、旧 token 授权新回合、Pending 工具被当作真实完成、根据耗时或聊天文案直接判失败。

### 验证义务与证据

| 验证义务 | 代表性证据 | 状态 |
| --- | --- | --- |
| 持久化边界、复用 ID 与真实工具状态 | 待登记直接测试 | Missing |
| 后端拒绝普通及自动推进，后继未启动，成功恢复保留审计 | 待登记跨进程测试 | Missing |
| 强制采用空重试的产出与独立原因 | 待登记完成事务测试 | Missing |
| 刷新或重启后展示失败和恢复入口 | 待登记投影与界面测试 | Missing |
