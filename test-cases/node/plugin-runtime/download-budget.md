# 插件下载：部署时限和取消边界

决策依据：[有界部署下载时限](../../../decisions/node/plugin-runtime/20261010-bounded-deployment-download-timeout.md)。

## Deployment download budgets must remain bounded and preserve default behavior

- 风险：大型官方包反复从头超时，或配置把安装变成无限等待并放松校验。
- 前置：Node 已取得合法的固定插件安装执行，部署可配置时限。
- 触发：省略配置、提供有效时限、非法类型/值/未知字段，以及安装取消。
- 必须成立：默认60/250秒不变；整数10–1200有效；总预算按三次尝试加70秒推导；现有连接时限、重试、大小、摘要、HTTPS和取消均保留。
- 禁止结果：用户执行载荷覆盖部署策略、非法配置静默回退、临时目录未结算就报告成功。
- 验证义务与证据：Desktop插件配置解析/边界及实际归档安装请求测试覆盖60/250、10/100、600/1870、1200/3670；真实Node进程插件恢复回归通过。状态 `Partial`：配置和调用接线有直接证据，慢网络完整固定官方CLI及取消全栈仍按M4实际记录补齐。
