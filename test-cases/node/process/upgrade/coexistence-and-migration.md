# 版本共存、迁移与权威事实保护

本文件记录已批准进程运行决策的核心验证义务；当前新体系尚无直接实现证据。

## Compatible Versions Coexist Without Replacing Live Guardians

### 风险

原地覆盖二进制或默认忽略未知语义，会让旧运行失去恢复程序或被新版本错误管理。

### 前置状态

旧 guardian 仍有活 Run 和恢复责任；提供兼容与不兼容的新宿主／guardian／数据版本组合。

### 触发

升级宿主，创建新 scope，再遇到不兼容语义或旧宿主已经故障的情况。

### 必须成立

- 兼容新宿主恢复管理旧 guardian，新 scope 使用新 guardian，旧运行不热替换、不重复启动。
- Node—宿主、宿主—guardian、程序—数据分别检查兼容；不理解影响语义的字段／政策／保证时在副作用前拒绝。
- 不兼容时由兼容管理／恢复版本或经验证的平台流程先收尾再切换；证据不足保持受限，保留仍需恢复的版本。

### 禁止结果

覆盖活 guardian 二进制；可解码即认定语义兼容；未知政策默认为安全；故障后删目录重新开始。

### 验证义务与证据

| 验证义务 | 验证方式与直接证据 | 状态 |
|---|---|---|
| 兼容升级保持旧运行身份与存续，新 scope 使用新版本 | 尚无直接证据；需双版本独立进程升级测试 | `Missing` |
| 三个边界分别拒绝不兼容语义，收尾和恢复先于切换 | 尚无直接证据；需版本矩阵与旧宿主故障测试 | `Missing` |

## Migration And Rollback Cannot Discard Authoritative History

### 风险

目录碰撞、锁替换或回滚数据库会遗忘接受／退休记录并复活旧权限。

### 前置状态

旧体系文件和新体系已接受请求、授权代次及退休记录均存在，恢复依赖旧版本程序；稳定锁正在约束管理权威。

### 触发

升级初始化路径、迁移中途强杀、执行程序回滚和普通版本／数据回收，再重投旧授权与旧 Run。

### 必须成立

- 新旧路径隔离或安全处理已有文件，稳定锁身份不被迁移／普通清理替换；有恢复责任的文件与可执行版本保留。
- 迁移失败可恢复且不回退授权、去重和退休事实；旧程序不理解新数据时拒绝，不能恢复旧库来适配。
- 新旧执行入口交接前明确停止旧运行，同一尝试不双跑。

### 禁止结果

覆盖历史运行文件；通过数据库回滚复活权限；删除恢复所需版本；用新目录掩盖未收尾责任。

### 验证义务与证据

| 验证义务 | 验证方式与直接证据 | 状态 |
|---|---|---|
| 已有布局、锁和恢复文件在初始化／迁移／回收中安全保留 | 尚无直接证据；需真实旧目录与迁移中断测试 | `Missing` |
| 程序回滚与迁移失败不倒退权威事实，旧请求仍拒绝 | 尚无直接证据；需新旧二进制、持久记录和重放测试 | `Missing` |
