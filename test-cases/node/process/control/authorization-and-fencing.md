# 授权、租约与实际执行点撤权

本文件三项用例均保留为未来授权／租约 ADR 的设计与验收输入，状态仍为 Missing，
不属于当前可信本机交付义务。当前宿主绑定证据见 recovery／protocol，不能替代 Controller 授权。
下文“必须成立”仅适用于未来启用对应能力；根决策的旧 D 编号不再作为当前实现映射。

## Only Verified Newer Authorization Can Replace A Node Instance

### 风险

自报更大代次或恢复旧授权记录会产生两个有效控制者。

### 前置状态

宿主已持久接受 Node 实例 A 的授权代次，Controller 的授权事实已持久保存。

### 触发

重投同一授权，提交同代次不同实例、旧代次和伪造高代次，再提交合法替代实例 B 的新授权；随后重启 Controller 与宿主。

### 必须成立

- 同授权重投幂等；冲突、旧授权与不可验证授权拒绝。
- 合法 B 可进入逐 scope 交接，但 guardian 未落实撤权前不得报告 scope 交接完成；重启后授权顺序不倒退。

### 禁止结果

以 Node 自报数值夺权；同代次绑定两个实例；实例授权成功直接放行依赖旧写入结束的工作。

### 验证义务与证据

| 验证义务 | 验证方式与直接证据 | 状态 |
|---|---|---|
| 只接受可验证且顺序合法的实例授权，重投不产生第二次接管 | 尚无直接证据；需授权与宿主持久接口测试 | `Missing` |
| 最高已接受代次及实例绑定跨重启保持，逐 scope 完成取决于 guardian | 尚无直接证据；需控制面与 guardian 分别故障的交接测试 | `Missing` |

### 决策依据

[根决策](../../../../decisions/node/process/control/0-authorized-generations-and-leases.md) D1、D2 与不变量 1、2。

## Expired Control Generations Cannot Be Revived By Reconnection

### 风险

把连接存活或迟到续约当作权限，会复活过期实例；错误的重启计时还可能延长已接受期限。

### 前置状态

已授权 Node 持有有效本地租约，分别存在终止策略与保留策略的 scope；可控制时钟和重启边界。

### 触发

Controller 暂时不可用，Node 正常本地续租；随后断开 Control，在期限前后分别重连，并注入休眠、宿主／系统重启与迟到续租。

### 必须成立

- Controller 临时不可用不阻止已授权实例本地续租；到期前可恢复，到期后旧代次永久失效。
- 终止策略关闭且不重开旧 scope，保留策略等待重新授权和业务恢复；两者均不自动释放资源。
- 实际执行点检查期限，跨重启按冻结算法恢复，不复用旧单调计时值或无依据延长期限。

### 禁止结果

用 Events／I/O 活动续租；因后台过期任务未执行而接受过期变更；迟到续租复活旧代次。

### 验证义务与证据

| 验证义务 | 验证方式与直接证据 | 状态 |
|---|---|---|
| 有效窗口可恢复而过期资格永久失效，Controller 中断不影响合法本地续租 | 尚无直接证据；需受控时钟与会话测试 | `Missing` |
| 失权处置遵守 scope 策略且不自动释放资源 | 尚无直接证据；需实际运行与资源关联验证 | `Missing` |
| 休眠与重启不复活权限或无依据延长期限 | 尚无直接证据；期限恢复算法冻结后需故障测试 | `Missing` |

### 决策依据

[根决策](../../../../decisions/node/process/control/0-authorized-generations-and-leases.md) D3、D4 与不变量 2。

## Revocation Fences Every Mutation And Undelivered Input

### 风险

仅在宿主验权会使已排入 guardian 的旧请求在交接后继续启动进程或写 stdin。

### 前置状态

旧控制者有启动、终止和 stdin 请求分别停在接受前、已接受未执行及即将写入的同步点。

### 触发

授权接管并撤权，再恢复旧 Node 和排队请求；同时让新控制者查询交接状态。

### 必须成立

- 撤权前接受的运行纳入原 scope 事实和后续处置；撤权后旧变更拒绝。
- 撤权完成前 guardian 必须落实执行点检查；完成后未交付的旧输入不再写入。已交付输入保留事实，由业务对账。

### 禁止结果

guardian 尚未落实就报告撤权完成；旧排队输入在完成后交付；把撤权成功当作先前副作用已结束。

### 验证义务与证据

| 验证义务 | 验证方式与直接证据 | 状态 |
|---|---|---|
| 启动／终止与撤权有明确先后且无漏管请求 | 尚无直接证据；需执行点同步屏障的并发测试 | `Missing` |
| 排队 stdin 在 guardian 写入点受代次约束，已交付事实不被抹除 | 尚无直接证据；需真实管道和插件确认对账 | `Missing` |
| 撤权完成、运行收尾与资源释放分别可观察 | 尚无直接证据；需接管期间的生产查询接口测试 | `Missing` |

### 决策依据

[根决策](../../../../decisions/node/process/control/0-authorized-generations-and-leases.md) D2、D3 与不变量 1、3。
