# 小队编组、维护与生命周期

决策依据：[小队根 ADR](../../../decisions/cloud/squad/0-workspace-scoped-human-agent-squads.md)（approved）。
以下是待实现系统承诺的直接验证义务，全部 Missing；不登记尚不存在的测试或将规格批准视作覆盖。

## Squad Members Must Have Typed Identities In The Same Workspace

- 风险：裸 ID、名称匹配或复制成员表导致跨租户编组、重复资格及资料漂移。
- 前置状态：两个租户，有效/停用人类成员、活动/退役 Agent，同名但不同 ID 的对象；部分用户属于多个租户。
- 触发：创建小队，添加人和 Agent，并发重复添加，在另一工作区尝试读写；修改显示名后重读。
- 必须成立：小队归属唯一且不可迁移；只接受同空间当前有效的类型化引用；对象可参加多队，同队仅一条有效编组；资料来自原权威。
- 禁止结果：跨租户对象被解析、用邮箱/姓名猜身份、Workflow 入队、复制模型凭据或重复有效关系。
- 决策依据：D1，不变量1、2、3。

## Maintainer Rights Must Follow Current Membership And Remain Local To The Squad

- 风险：创建者永久特权、维护者被误作管理员，或失去维护者后无法接管。
- 前置状态：普通成员、创建者、维护者、租户管理员及无资格用户；有一队或多队。
- 触发：创建、改名、编辑职责、增删成员、授予/撤回维护权、退出；用过期版本重放写请求。
- 必须成立：创建与初始维护者原子建立；管理员可管理所有本租户小队，维护者只管理本队；其他成员可读、可创建、可退出自己。
- 禁止结果：created_by 绕过撤权、普通维护者对外邀请/审批、Agent 成为维护者、旧版本覆盖撤销或归档。
- 决策依据：D2，不变量2、4、6。

## Optional Leaders Must Not Imply Execution Or Survive Agent Retirement

- 风险：leader 配置变成隐式执行、引用失效 Agent，或重装插件复活旧职责。
- 前置状态：无 leader 小队、普通 Agent 成员和另一活动 Agent；存在真实运行与个人模型配置。
- 触发：设置/更换/清除 leader，直接移除现任 leader，退役后重装 Agent，选择小队或编辑职责。
- 必须成立：可无 leader 编组；设置与必要入队原子完成；更换后旧 Agent 留作普通成员；移除须明确更换或清除；退役关闭关系和有效 leader，历史保留。
- 禁止结果：静默替换 leader、重装恢复旧编组、启动/取消运行、发布可执行 Team 目标或消耗私人模型。
- 决策依据：D3、D4，不变量4、5、6。

## Removal And Archival Must Close Effective Membership Without Erasing History

- 风险：已撤销资格残留、归档队伍继续接受成员、历史被删除或重入恢复维护权。
- 前置状态：有成员、维护者、leader、待接受邀请及已准入运行的小队。
- 触发：并发加队与移除/归档；直接编辑归档队伍、尝试恢复；成员显式重新入队。
- 必须成立：移出某队仅结束本队关系；归档关闭全队关系和 leader，停止新增/编辑，从活动列表隐藏；当前有权者仍可查历史。竞争结果符合确定的提交顺序。
- 禁止结果：归档后普通编辑恢复、隐式终止运行、重写负责人/历史、重入恢复旧维护权。
- 决策依据：D1、D4，不变量3、6；工作区撤权另见 [tenancy 用例](../tenancy/targeted-joining-and-revocation.md#workspace-revocation-must-close-squad-rights-and-rejoining-must-not-revive-them)。

## Squad Views Must Reflect Real State Across Accounts And Reconnection

- 风险：界面继续演示假队伍、待加入被算作正式成员、丢失 SSE 后资格长期漂移。
- 前置状态：两个真实登录账号、两个工作区；有正式队员、未绑定接收人的邀请、待审批申请与无 leader 小队。
- 触发：创建/编辑/加入/退出后另一浏览器观察；断线重连、重新聚焦、切换工作区；加载失败或访问旧演示详情 URL。
- 必须成立：真实人类/Agent计数与职责，待兑换/审批另列，正确导航；空、失败、无权及归档分别说明，通知只提示重新读取。
- 禁止结果：失败回退 seed、伪造用户名/在线状态、未配置却宣称可执行、缓存跨工作区泄漏。
- 决策依据：D5，不变量1、5、6。

## Fresh And Upgraded Databases Must Not Import Demo Squads

- 风险：迁移回填全员或 seed，或先开放创建后遗漏撤销写入者。
- 前置状态：空库与含真实成员、邀请、活动/退役 Agent 的旧库。
- 触发：前向升级，显式创建首队，成员停用及插件退役；重复运行正常迁移过程。
- 必须成立：旧身份与迁移校验保持，小队由显式操作产生；开放写入时撤销/退役关闭责任同时可用。
- 禁止结果：默认全员队伍、导入假身份、重建真实数据库、产生无撤销路径的编组。
- 决策依据：迁移与落地，不变量1、3、6。
