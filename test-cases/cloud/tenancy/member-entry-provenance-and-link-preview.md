# 成员加入来源与只读链接预检

决策依据：[成员加入来源与私有链接预检](../../../decisions/cloud/tenancy/20261027-member-entry-provenance-and-link-preview.md)（`approved`）。本文件登记新增或改变的义务；既有加入测试不能自动证明这些行为。尚未登记直接证据的义务全部为 `Missing`，不以候选实现或部署记录代替证据。

## Preview Requires The Exact Gateway Boundary And Never Writes

- 风险：匿名豁免扩散到写接口，或预检触发身份创建及业务写入。
- 前置状态：公网与企业目录两种部署；无会话、有效/无效用户凭据、伪造内部身份头和非 Gateway 服务身份。
- 触发：向预检路径及相邻路径发送不同方法请求；同源与异源请求、超过限流阈值；直接调用 Cloud。
- 必须成立：仅 POST /api/v1/join/links/preview 可无会话经过 Gateway；同源校验、限流、内部头清除、服务身份及 caller 绑定全部生效；企业目录入口关闭。任何预检不创建用户，不改变业务表计数、内容或版本。
- 禁止结果：兑换/成员接口被匿名放行；伪造用户头获得详情；无效已提供凭据被当成有效身份；预检产生用户、成员、申请、幂等或审计写入。
- 决策依据：ADR D1。

## Anonymous Preview Reveals Only Kind And Coarse State

- 风险：错误原因、目标或使用者泄露工作区人员信息；登录前后的信息边界混淆。
- 前置状态：active、used、expired、revoked、未知链接及失活工作区；签发者失权、定向目标归档或不合法的链接；有效成员和待审批用户。
- 触发：分别匿名和登录预检，构造多种失效条件重叠。
- 必须成立：匿名仅返回类型及 active/used/expired/revoked/unavailable；签发者或目标失效对匿名统一 unavailable，不新增状态或原因细节。已登录有效用户才可见目标工作区及自己的成员/申请状态；used、revoked、expired 重叠时按 ADR 顺序判定。已有成员可进入仍活动的工作区，失活工作区无入口。
- 禁止结果：匿名返回工作区、签发者、目标、使用者或名册；把服务故障当成有效链接或空列表；泄露他人的申请状态。
- 决策依据：ADR D1。

## Redemption Rechecks State And No Op Never Consumes An Invitation

- 风险：预检后撤销仍成功；已有成员烧掉邀请；空操作重放重新授予资格。
- 前置状态：有效 admin/member、新成员、停用成员；同一邀请已预检成功，另有已消费、到期或撤销链接。
- 触发：预检后改变有效性再提交；已有成员与新成员并发接受；同键重放、异键竞争及同键不同内容；移除成员后重放旧成功。
- 必须成立：真正提交在原事务重验；新建/恢复必须有有效邀请；普通邀请目标为空，已有有效成员保持角色且不消费、不通知、不写来源；其他合法接受者仍可使用。真实准入只有一次消费；重放只返回历史命令结果，不重新授权，进入资源重验当前资格。
- 禁止结果：使用预检结果绕过校验、两人消费同一邀请、admin 被降级、旧命令复活成员、错误码兼容性丢失。
- 决策依据：ADR D1、D2。

## Join Provenance Commits Atomically Only For Real Membership Changes

- 风险：已入会但来源缺失、失败留下假历史，或编组变化伪造工作区加入。
- 前置状态：创建工作区、邀请、审批和目录加入渠道；有效、未加入及停用成员；重复命令与来源写入失败点。
- 触发：建立/恢复资格、审批竞争、目录重试；在资格、来源、消费或审批提交前注入失败；已有成员仅新增编组或已在全部目标队伍。
- 必须成立：每次真实建立/恢复资格同事务追加租户、用户、渠道、授权人、时间及关联引用。邀请、审批、目录路径均遵守；任一步失败全部回滚。纯入队仅记编组来源；新增任一编组可消费定向邀请，但没有资格或编组新增时不消费、不通知。开发身份不伪装邀请。
- 禁止结果：半条资格/来源记录、重复审批或幂等重放追加历史、纯编组被记作再次加入、来源成为第二份权限权威。
- 决策依据：ADR D2、D3；小队情形是交集验证义务，不代表本轮交付小队实现。

## Provenance Reads Enforce Current Admin And Tenant Isolation

- 风险：仅隐藏按钮仍可越权读取来源或重新加入历史。
- 前置状态：两个租户的管理员、普通成员、被撤权管理员；存在多次加入历史与更名人员。
- 触发：读取当前来源及历史，替换租户/成员标识，撤权后重复请求。
- 必须成立：服务端检查当前管理员和租户边界；普通成员仅见基础名册；显示名随当前名册，历史 actor ID 与链接引用保留。
- 禁止结果：跨租户来源、普通成员读取管理员详情、改名重写历史身份或旧管理员继续读取。
- 决策依据：ADR D3。

## Upgrade Preserves Existing Facts Without Guessing Join Provenance

- 风险：以 consumed_by 错认来源，迁移破坏已有成员或 token，客户端升级失配。
- 前置状态：旧库包含有效/停用成员、已被已有成员消费的邀请、未消费邀请、pending/已决定申请；另有空库。
- 触发：前向迁移并按迁移→Cloud/Gateway→前端升级；旧客户端调用原写接口。
- 必须成立：旧表、摘要、版本和成员/申请事实保留；无法严格证明的来源显示“未记录”，不推测回填；新发生加入才按新规则记录；两类链接期限不变，旧错误码保留，生成契约及中英文文档同步。
- 禁止结果：原文 token 回填、把消费人当加入人、重建真实用户数据库、旧客户端误获权限。
- 决策依据：ADR D3、D4。

## Join Pages Preserve Intent And Discard Link Plaintext

- 风险：登录丢失加入意图、审批前误显示已加入，原文离开弹窗后仍可恢复。
- 前置状态：匿名受邀人、待审批人、已有成员和管理员；桌面/窄屏及中英文界面。
- 触发：匿名预检、登录回跳、申请/审批与失败重试；生成链接后重复复制、关闭、切工作区、离开再返回。
- 必须成立：匿名失效可直接理解，登录恢复原加入流程且提交重新校验；待审批不授予资格；两类链接备注不改变准入。原文仅生成弹窗内存持有，重复复制不改变次数，关闭/切换/离开即丢弃；管理列表可展示创建者、时间、状态、使用者或申请统计；失败和空列表可区分。
- 禁止结果：回跳自动兑换、待审批者直接进入资源、重新打开恢复原文、失败显示成功或空列表。
- 决策依据：ADR D1、D4。
