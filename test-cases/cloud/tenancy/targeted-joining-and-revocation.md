# 定向加入、签发者失权与编组撤销

依据 [tenancy 后续 ADR](../../../decisions/cloud/tenancy/20261027-squad-targeted-joining-and-inviter-revocation.md)
（approved）。新增验证义务全部 Missing；既有普通邀请用例的覆盖不自动证明新编组、消费或来源规则。
小队本身的管理权限与归档义务见[小队用例](../squad/membership-and-lifecycle.md)。

## Joining Must Atomically Grant All Frozen Targets Or Grant Nothing

- 风险：邀请半消费、只加入部分队伍、客户端替换目标或普通成员升级权限。
- 前置状态：有效管理员，普通/定向邀请，新用户、停用成员及现有管理员；目标包括活动、归档或跨租户小队。
- 触发：签发、修改请求中的目标、接受前目标改名/归档；在资格建立与编组间注入事务失败。
- 必须成立：服务端冻结最多20个不同目标，按ID解释；资格、全部新增编组、来源和消费原子提交，目标为空只加入工作区；当前有效角色保留。
- 禁止结果：维护者对外签发、通过query扩大目标、失效目标被忽略、普通邀请授维护权、失败消耗token或残留半加入。
- 决策依据：D1、D2，不变量1、2、3、7。

## Noop Acceptance Must Preserve The Token While Real Grants Consume It Once

- 风险：老成员误耗单次邀请，或新增编组未消费使多人获授；并发/重试重复通知或重新授权。
- 前置状态：普通邀请目标为空；定向邀请中接收者可能已在全队或仅部分队伍；未加入用户同时持有该链接。
- 触发：接受、同键重试、同键异请求、异键与异用户并发；空操作后成员被移除再重放。
- 必须成立：无资格建立/恢复且无新增编组则不消费、不通知；有任一新增资格或编组即消费一次；空操作后其他合法用户仍可接受；旧幂等结果不重新授予。
- 禁止结果：空操作占用token、重复有效关系/消费、重放恢复撤销权、同键不同请求被接受。
- 决策依据：D2，不变量1、3、8。

## Anonymous Preview Must Hide Identity And Target Details

- 风险：token预检泄漏工作区与成员，或预检成功被当作提交时授权。
- 前置状态：匿名、有效登录、无效身份；active/used/expired/revoked/unavailable链接，以及签发者失权或目标归档的链接。
- 触发：通过受限预检读取，跨源或企业目录部署访问；登录回跳；预检后撤销、失权或归档再提交。
- 必须成立：匿名仅kind/state，签发者或目标问题统一unavailable；有效登录才给最小确认信息，不能读完整名册；预检只读，提交重验。
- 禁止结果：匿名返回名称或详细失效原因、原文token进入日志/外部回跳、绕过同源/限流/目录部署边界、凭旧预检建立资格。
- 决策依据：D1、D2，不变量2、7、9。

## Join Provenance Must Describe Only The Qualification That Actually Changed

- 风险：老成员加队伪造成工作区重新加入，或资格、来源与消费分事务而漂移。
- 前置状态：新用户、停用用户、有效成员；邀请、审批、目录三种加入渠道；有历史来源未记录的数据。
- 触发：分别建立/恢复租户资格、仅新增编组、纯空操作；中间失败、重试与非管理员读来源。
- 必须成立：三渠道均只在建立/恢复租户资格时同事务追加membership_join_events；纯编组来源只记编组关系；同时变更两层时两种来源同成败；工作区来源仅管理员可读。
- 禁止结果：纯加队新增工作区来源、回填猜测历史、失败/重放重复来源、普通成员越权读取管理来源。
- 决策依据：D2、D4、D6，不变量1、3、8。

## Inviter Revocation Must Permanently Invalidate Outstanding Links

- 风险：签发者失权后仍可邀请，复权或全局用户恢复使旧链接复活，失败降级误撤邀请。
- 前置状态：多租户管理员，有普通/定向邀请、申请链接、已消费邀请与pending申请；包括最后一名管理员。
- 触发：降级、成员停用、全局用户停用/删除、复权；与签发/兑换并发；另一管理员处理已有申请。
- 必须成立：成功撤权永久终止全部受影响租户未消费邀请和新申请入口；先兑换后撤权保留已授资格；先撤权后兑换拒绝；失败的最后管理员降级无副作用；既有申请可独立审批。
- 禁止结果：仅检查当前role而复活旧token、全局撤销漏租户、自动撤销已加入成员或自动驳回既有申请。
- 决策依据：D3，不变量4、5、7。

## Approval And Directory Joining Must Respect The Original Target Intent

- 风险：申请A被当作申请B批准、目标失效仍批准半套资格、目录加入绕过在职核验。
- 前置状态：同用户同租户已有pending申请，目标可相同或不同；用户可能经其他渠道先入会；目录加入环境。
- 触发：重复申请、更换链接、并发审批、目标归档后审批；目录核验后撤销管理员/归档目标再提交。
- 必须成立：同目标复用pending，异目标冲突且不改原意图；批准重验并原子建立全部关系/来源/决定；失效保持pending；有效成员角色保留，已全入队只完成审批、不发加入通知。
- 禁止结果：审批前有资格、失败已标approved、非管理员审批、跨网络持锁或借小队开启内网链接加入。
- 决策依据：D4，不变量1、2、3、5、7、8。

## Workspace Revocation Must Close Squad Rights And Rejoining Must Not Revive Them

- 风险：停用成员的编组/维护权残留，重入或幂等重放恢复旧权限，丢事件延迟撤权。
- 前置状态：多租户、多队人类维护者，有已准入运行与建立中的编组；包括只降级未停用的管理员。
- 触发：成员移除或用户全局停用/删除，与入队并发；旧请求、事件流、重启、重新接受邀请或审批。
- 必须成立：资格撤销与所有受影响编组/维护权同事务关闭；重入只得本次目标；只降级保留独立本队维护资格但立即失去邀请权；已准入运行按原生命周期收尾。
- 禁止结果：等缓存/SSE才撤权、无资格却有有效编组、重入复活旧维护权、删除历史或擅自取消运行。
- 决策依据：D5，不变量4、6；小队根D4。

## Policy Upgrade Must Preserve Valid Legacy Intent And Fence Old Writers

- 风险：升级销毁真实数据、猜测旧目标/来源、旧实例继续消费空操作或绕过撤权。
- 前置状态：新库及包含有效/无权签发者、已消费/撤销链接、pending申请、历史来源缺失和既有成员的升级库；新旧写入实例混用。
- 触发：前向迁移与策略启用、迁移失败、旧二进制写入或回滚。
- 必须成立：旧目标为空；保留原token摘要、期限、单次限制与已发生事实，当前无权链接失效；合法旧链接绑定启用资格并记录时点；不推断升级前失权历史；全部写入者满足门禁才开放。
- 禁止结果：改旧迁移、重建真实库、seed/全员回填、伪造来源、失败时开放旧写入路径或旧二进制绕过新规则。
- 决策依据：D6，不变量1、4、6、7。
