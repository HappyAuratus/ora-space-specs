# 任务混合串行交接：评审草案

依据[混合任务交接提案](../../../decisions/cloud/issue-run/20261025-mixed-task-execution-handoffs.md)。
本文与 proposed ADR 一起用于审阅用户要求的验证范围，尚不是批准后的系统承诺；批准时按最终结论重新核对。
新增义务全部为 Missing，不将已有 Agent-only 顺序或旧入口工作流执行证据提升为混合接力证据。

## Every Entry Shares One Ordered Task Occupancy

- **风险：** 新旧入口、两个调度器或两个实例同时启动；纯计算工作流在排队期间偷偷推进；同目标唯一索引阻断合法队列。
- **前置状态：** 一个任务已有 Agent，占用同一数据库的两组 Cloud worker；其他任务也有排队工作。
- **触发：** 交错任务消息、旧评论 targets、手动运行、Workflow Confirm、旧 Thread 追加；连续排队两个相同工作流。
- **必须成立：** 请求顺序按接受事务固定，任务占用最大为 1；前缀先完成，屏障后不能插旧会话；其他任务能持续推进。
- **禁止结果：** 只靠按钮禁用；交付/释放中超占；同键重复执行；晚到消息反过来挡住早期已接受请求。
- **验证义务与证据：** 真实 PostgreSQL 双实例生产接口竞争，记录每次占用变更与各执行开始时刻；重启、扫描公平性及一致锁序测试。**Missing**。
- **决策依据：** D1、D2，不变量 1、3。

## Confirm Freezes Intent While Dispatch Freezes Predecessors

- **风险：** 排队后改跑新版；上下文冻结太早；配置失效后自动换用户；Confirm 响应丢失创建两次运行。
- **前置状态：** Agent 尚在工作，用户确认旧发布版本工作流；其后发布新版、修改个人模型配置。
- **触发：** 重复点击、丢失创建 interaction/Confirm 响应并刷新；原 Agent 完成后派发；撤销成员或冻结绑定。
- **必须成立：** 原版本与表单不变，收到前序最新成果和历史；实际接续的 Revision 与历史范围可见且与派发事实一致；同键对账指向同运行；失效明确阻塞且不悄悄重绑。
- **禁止结果：** 重试覆盖已确认输入；先创建副作用再落幂等身份；同键不同载荷被当成新运行或无声成功；卡片显示的基线与实际执行的不同。
- **验证义务与证据：** 组件到真实 API 的回放、并发 Confirm、PG 计数和冻结输入比对，覆盖创建与确认两个未知结果窗口；记录确认与派发两个时点的基线差异，核对卡片显示与实际传入一致。**Missing**。
- **决策依据：** D3，不变量 2、6、7。

## Mixed Successors Receive Verified Code And Attributed Results

- **风险：** 能看到卡片却没接上代码；工作流输出与 activity 双计；恢复完整历史的虚假承诺。
- **前置状态：** 同任务排队 Agent → Workflow → Agent，以及 Workflow → Workflow；每步新增独立文件与结果标记。
- **触发：** 各步依次正常完成，后继读取前序实际文件并引用其输出；加入超预算文本和不可读来源。
- **必须成立：** 新 Workspace 恢复正确 Revision，后继实际读取文件；历史最多 20 单元/64 KiB，来源去重、截断缺失可见。
- **禁止结果：** 只靠提示里复述口令证明代码恢复；内部日志/秘密进入历史；同名工作流替代原 ID；纯计算步骤把基线清空。
- **验证义务与证据：** 正式 Agent、真实工作流、Git Server 与独立 Workspace 联合验收；正文预算、中文 UTF-8 截断及多 output 顺序测试。**Missing**。
- **决策依据：** D4，不变量 3、4、7。

## Failure And Cancellation Preserve The Mixed Barrier

- **风险：** 一方失败后另一执行器继续；取消等待项误停当前执行；恢复偷偷重跑终态工作流。
- **前置状态：** 工作流在人工等待、自动重试、保存或释放中，后面有不同成员提交的 Agent/Workflow 请求。
- **触发：** 取消等待项、停止当前执行、注入交付失败或 Node 断线、重启、无权限恢复、有权限明确恢复。
- **必须成立：** 等待/重试占用持续；停止暂停队列；失败与残留阻塞；取消未开始项不影响当前工作；授权和原顺序保持。
- **禁止结果：** 超时当作释放、另一成员借模型结束他人会话、确认晚期失败跳过早期屏障、resume 501 被解释成已恢复运行。
- **验证义务与证据：** 多成员真实接口、持久化重启与 Git/Node 故障矩阵；明确放弃成果和恢复动作分别验证。**Missing**。
- **决策依据：** D2、D5，不变量 3、5、7。

## Conversation Routes By Type And Recovers The Same Run

- **风险：** workflow ID 被发给 Agent API；刷新后重新执行；历史选择改变当前停止对象；@ 文本意外分派。
- **前置状态：** 默认对话有 Agent 历史及工作流队列，另有未发送草稿；名册包含未发布/失效目标。
- **触发：** 选择/@、取消表单、切换发布版本、审阅确认、断线重载、从执行记录进入、权限撤销。
- **必须成立：** 选择无执行副作用，类型清楚，冻结版本准确；卡片稳定定位，队列与保存/释放状态可见；草稿保留。
- **禁止结果：** 模仿 Agent Thread、自动提交旧草稿、仅评论执行、阅读历史启动沙盒、权限拒绝后残留旧任务内容。
- **验证义务与证据：** MSW 组件测试与真实任务页选择→Confirm→执行→详情链路；回归仅评论、Agent 续聊和旧任务动态。**Missing**。
- **决策依据：** D6，不变量 6、7。

## Upgrade Preserves Identity And Rejects Unresolved Work

- **风险：** 新旧 worker 同时派发；迁移重写旧消息序号；残留被错误当作空队列。
- **前置状态：** 升级前库有历史 Agent/Workflow、未发送草稿、等待请求、失败屏障或未释放 Workspace。
- **触发：** 正常排空后升级；另分别在等待、执行、交付、释放、残留未决时尝试启用新队列。
- **必须成立：** 原历史身份与含义保留，未处理工作阻止切换；新迁移可在全新库与既有库执行，只有新接受意图进入新队列。
- **禁止结果：** 自动取消用户请求、删库重建、伪造历史 Revision、旧版本 worker 绕过新占用、迁移使失败自动成功。
- **验证义务与证据：** 旧版本数据集升级、迁移约束与启用门禁测试；协调升级演练及备份恢复检查。**Missing**。
- **决策依据：** 兼容与落地，不变量 1、5、6。
